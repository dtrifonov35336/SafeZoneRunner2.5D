# SAFE ZONE RUNNER — ПЛАН РЕАЛИЗАЦИИ

Версия: 1.0
Дата: 06.09.2026

## Цель

Создать коммерчески ориентированную мобильную 2D survival/endless runner игру для Android с дальнейшей публикацией в RuStore и Яндекс Играх.

Игрок выбирает персонажа, бежит в составе огромного потока эвакуируемых людей от окраины города к убежищу, пробирается через толпу и препятствия, пока сзади наступают зомби/монстры. Добравшись до убежища, игрок попадает в ангар, получает награды, покупает/улучшает снаряжение и начинает следующий раунд.

Главный принцип: сначала доказать, что базовый забег интересен, и только потом масштабировать контент и монетизацию.

# 2. ЭТАП 1 — СТАБИЛЬНЫЙ ПРОТОТИП

Цель: получить стабильный вертикальный runner.

Порядок:

1. Проверить движение Player.
2. Проверить границы X.
3. Проверить скорость дороги.
4. Проверить камеру.
5. Проверить Portrait на разных разрешениях.
6. Проверить отсутствие разрывов дороги.
7. Очистить Console от критических ошибок.
8. Сделать резервную копию проекта.

Результат: персонаж остаётся примерно в нижней части экрана, дорога непрерывно движется вниз, Player управляется влево/вправо.

# 3. ЭТАП 2 — АНИМАЦИЯ

Система:

Player
└── Visual
    ├── SpriteRenderer
    └── Animator

Основная анимация:

Frame 1 — левая нога
Frame 2 — правая нога
Frame 1
Frame 2
...

Включить Loop Time.

Animator отвечает за внешний вид. PlayerMovement отвечает за физическое положение Player.

Не анимировать корневой Player по миру.

Позже добавить:
- Idle;
- Run;
- IsRunning;
- небольшое покачивание/bob;
- эффекты усталости.

# 8. ЭТАП 7 — ЗОМБИ

Это одна из главных особенностей игры.

Сначала сделать только один простой тип зомби.

Создать:
- Zombie;
- ZombieSpawner;
- HordeManager.

Не нужен сложный AI.

Главная задача первой версии — визуально и механически создать ощущение, что опасность постоянно приближается сзади.

---

# 9. ЭТАП 8 — СИСТЕМА ПРЕСЛЕДОВАНИЯ

Создать параметр ChaseDistance.

Если игрок:
- хорошо проходит участок → дистанция увеличивается;
- сталкивается/теряет время → дистанция уменьшается.

Если ChaseDistance <= 0:
→ поражение.

Это станет основной системой напряжения.

# 11. ЭТАП 10 — ВЗАИМОДЕЙСТВИЕ С ТОЛПОЙ

Игрок должен не просто проходить сквозь декоративный фон.

При контакте с толпой:
- небольшое замедление;

- мягкое сопротивление;
- ограниченное влияние на скорость.

Не создавать физическую «кашу» из Rigidbody2D.

2. поток эвакуируемых;

4. баррикады;
5. мусор;
6. плакаты/баннеры на ткани;

Важно:

- второй дорожный сегмент должен продолжать первый по цвету и стилю;
- под плакатом безопасной зоны должен быть свободный проход.
